## Repo Overview

This repository contains code developed for a university project.  
The work builds upon the **RDL framework** ([paper](https://arxiv.org/pdf/2312.04615)) and experiments are conducted using **RelBench** ([paper](https://arxiv.org/pdf/2407.20060)) as the evaluation benchmark.
